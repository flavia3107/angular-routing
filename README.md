# 🗺️ Angular Routing Mini Project

This mini project is part of the **Angular - The Complete Guide (2025 Edition)** Udemy course.  
It demonstrates the use of **Angular Routing** for navigating between different views in a single-page application.

---

## 📌 Features

- **Setup of Angular Router** for seamless navigation  
- **Route configuration** with multiple routes  
- **Nested routes** and child routing  
- **Dynamic route parameters** and query parameters  
- **Route guards** for protecting access  
- **Navigation with routerLink and programmatic navigation**  

---

## 🛠️ Tech Stack

- **Languages**: TypeScript, HTML, CSS/SCSS  
- **Framework**: Angular 17  
- **Routing**: Angular Router  
- **Styling**: Angular Material, SCSS  
- **Tools**: VS Code, Git, GitHub  

---

## 🎯 Learning Objectives

✅ Master **Angular Router** basics and advanced features  
✅ Implement dynamic and nested routes  
✅ Understand route lifecycle hooks and guards  
✅ Build responsive and user-friendly navigation
